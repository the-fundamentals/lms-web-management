## Key implementation decisions

- Routes compose schedule into the classroom shell; classroom never imports `@/features/schedule`.
- List filter `size: 50` — lms-core-api rejects `size > 50` on `ClassroomSessionFilter`.
- Weekly double-submit uses a sync `savingRef` because React state alone is too late for same-tick double submit.
- Dirty leave uses TanStack `useBlocker` (in-app Back/tab) plus `enableBeforeUnload` — first schedule forms to cover in-app leave; earlier units used beforeunload only.
- Overview failed-load UI uses shared `RequestStatus` / `ErrorScreen`; a dedicated overview reject test was dropped after Vitest treated the rejected `queryFn` as an unhandled test failure.
