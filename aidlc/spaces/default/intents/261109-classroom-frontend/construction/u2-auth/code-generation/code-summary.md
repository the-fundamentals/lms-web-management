# Code Summary: u2-auth

## Files created/modified

Sign-in, the name form, and sign-out live under `src/features/auth/` in subfolders. Thin TanStack Router files under `src/routes/` only wire the URL:

- `src/routes/__root.tsx` — root layout with `Outlet`.
- `src/routes/index.tsx` — `/` renders `HomePlaceholder` (classrooms come next; U3 owns the real home).
- `src/routes/sign-in.tsx` — `/sign-in` renders `SignInRoute`.
- `src/routes/onboarding.tsx` — `/onboarding` renders `OnboardingEntry` with `onSignIn` from `useAuth`.
- `src/routeTree.gen.ts` — generated by `@tanstack/router-plugin`. Do not hand-edit.
- `src/features/auth/screens/sign-in-route.tsx` holds the sign-in session branch. After the server rejects the session, the Sign in screen that stays up still says the entries on the previous form were not saved, including once `auth.isAuthenticated` is false.
- `src/features/auth/screens/onboarding-entry.tsx` reads the profile for `/onboarding`.
- `src/features/auth/screens/home-placeholder.tsx` is the interim `/` after a known profile.
- `src/features/auth/session/session.ts` reads `VITE_COGNITO_AUTHORITY` and `VITE_COGNITO_CLIENT_ID` at runtime. A missing value throws a configuration error that does not include either value. A signed-in user stores the access token with `setAccessToken`. The id token stays in this module. Sign-out clears both. `onSigninCallback` removes `code` and `state` from the URL. Scope is `openid email profile`. Response type is `code`. Redirect is this app's origin plus `/sign-in`. PKCE stays on. `setPageLeave` lets the app bind SPA navigation; `leaveFor` uses that leave function.
- `src/features/auth/profile/profile-gate.ts` sends profile 200 to `/`, `ACCOUNT_PROFILE_NOT_FOUND` to `/onboarding`, and HTTP 401 to `/sign-in` with notice `unsaved`. Any other failure stays an error. Email is ignored. The result does not grant ADMIN.
- `src/features/auth/profile/profile.ts` reads with `getMyAccountProfile` and saves with `updateMyAccountProfile`. The save body is `firstName`, `lastName`, and `avatarKey`. The id token is the `X-ID-Token` header. Neither token is logged.
- `src/features/auth/profile/avatar-key.ts` holds the placeholder avatar key `public/00000000-0000-4000-8000-000000000001`. A missing profile sends that key. A profile that already has a key sends that same key again. The form does not show the key.
- `src/features/auth/screens/sign-in-screen.tsx` is the Sign in screen. No sidebar. Notice `unsaved` says the entries on the previous form were not saved. A token prop is not rendered.
- `src/features/auth/screens/name-form.tsx` is the first-and-last-name form. Empty fields name that field and keep the other value. Vietnamese text stays as typed. A dirty form asks before leaving. Waiting uses the shared loading screen. Failure uses the shared error screen and offers retry.
- `src/features/auth/profile/profile-entry.tsx` runs the profile read and renders the name form, Sign in, or the shared error screen.
- `src/features/auth/screens/sign-out.tsx` exports `signOut` for the account menu. It clears the access token, ends the OIDC session, and goes to `/sign-in` with no token in the URL. The button is `data-testid="sign-out"` and is not a sidebar item.

`src/main.tsx` mounts `QueryClientProvider`, `AuthSessionProvider`, and `RouterProvider` with the generated route tree. It imports the shared API client so interceptors bind. `setPageLeave` uses `router.history.push` so `leaveFor` stays in the SPA. Missing Cognito env shows `ErrorScreen` with a reload retry (`Cognito authority/client id missing — fill \`.env\``).

`vite.config.ts` adds `tanstackRouter({ target: 'react', autoCodeSplitting: true })` before `react()`, keeping the `@` alias and Tailwind. Official defaults: `routesDirectory` `./src/routes`, `generatedRouteTree` `./src/routeTree.gen.ts`.

## Key implementation decisions

Route files import a screen and render it. Session logic, forms, and tests stay in `src/features/auth/` subfolders. That feature may import `src/shared`. A feature must not import another feature.

The unsaved notice is stored beside the bearer latch. `releaseServerRejection` clears the latch once the local user is gone, so a later sign-in can store a token. The notice stays until a new session is remembered, because the sign-in screen re-renders after `isAuthenticated` becomes false.

The shared bearer store keeps the access token only. The id token stays in the session module and is sent only on the profile update.

A known profile's destination is `/`, which renders `HomePlaceholder` until u3-classroom owns the classroom list.

Page padding is `p-6` (24px) and the stack gap is `gap-4` (16px). Colors are semantic classes. No hex value is set in this unit's screens.

The placeholder avatar key `public/00000000-0000-4000-8000-000000000001` is the only key a missing profile may send. Image upload is out of scope.

## Deviations

- The shadcn CLI wrote `import { cn } from "cn"` in `input`, `label`, and `card`. Those imports now use `@/shared/lib/cn`, the same path as `button`, `alert`, and `skeleton`.
- `AuthSessionProvider` is built with `createElement` inside `session.ts`. JSX does not parse in that `.ts` file.
- A known profile and a saved name call `leaveFor("/")`. `main.tsx` binds that to `router.navigate` with the generated route path union so navigation stays in the SPA without `as never`.
- A profile 401 calls `markSignedOutByServer`, which clears the bearer token and removes the local OIDC user. `SessionBridge` does not copy that token back while the rejection stands. The unsaved notice is a separate flag so the sign-in route can keep it after that removal.
- This unit wires the runnable app (`main.tsx`, `__root.tsx`, route tree) so `npm run dev` shows Sign in before u8-app. U3 still owns the real classroom home.
