## Key implementation decisions

Features do not import each other. Routes compose auth, `app-shell`, and `classroom`. Overview receives stats props from the route so app-shell never imports classroom.

Overview vs Classrooms: `/` is the snapshot; `/classrooms` is the searchable list (person Request Changes). Create includes optional banner/payment (person Request Changes).
