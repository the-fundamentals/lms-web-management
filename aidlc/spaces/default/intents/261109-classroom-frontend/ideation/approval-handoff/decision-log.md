# Decision Log

Drawn from `intent-statement.md`, `stakeholder-map.md`, `scope-document.md`, `intent-backlog.md`, and `wireframes.md`.

| Decision | Outcome |
| --- | --- |
| Who it is for | The owner, an English teacher. The only stakeholder and the only user for now. It might extend later. |
| Why | Excel attendance is too much work. Money across classes is part of the same need. |
| Success | Most of the main classroom workflow is usable. Screens look good, with a documented design and palette. Attendance and finance work across classes. Most finished backend capabilities are on the frontend. Each attendance has a short note of what the student learnt. |
| When it is done | When the owner is happy. No deadline. A short note when a slice is ready. |
| This version | Five slices, in order: enter the app, classrooms, members, attendance with calendar and schedule, finances. Review after each slice. |
| Not this version | Google Meet links and automatic attendance. The end-of-month tuition email. Profile and file storage as their own slice. |
| Helpers | In the app, off the main screens, loosely coupled where they can be moved to another project. |
| Sketches | Structure only. Laptop first, mobile web later. The build does not copy them one to one. |
| Login | First visit: sign in, then name, then home. Later visits: sign in, then home. |
| Classrooms | Create returns to the list. The list is the home screen. A row opens the classroom. |
| Members | Add a person who already has an account, then return to the members list. |
| Schedule | Recurring is the weekly time. Adhoc is one new session. |
| Attendance | Open the session and mark every student, with an optional note. |
| Money | A payment plan is the student's price per session. |
| Open sketch notes | Accepted as known risks. Listed in `initiative-brief.md`. |
| API notes | Checked, then set aside for later. Listed in `scope-document.md`. |
| Market research | Not in this plan. |
| Feasibility study | Not in this plan. |
| Team | The owner builds it. No separate team. |
