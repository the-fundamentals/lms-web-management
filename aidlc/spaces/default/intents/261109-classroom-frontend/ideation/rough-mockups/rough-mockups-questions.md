## Q3. [Product owner] How do you want to mark attendance?

Each attendance still has a short note for what the student learnt. This chooses the screen you use in class.

A. One screen for the class: each student, present or absent, and a note
B. One student at a time
C. The calendar first, then the class, then the students
D. Not yet defined
X. Other (please specify)

[Answer]: A. One screen for the class: each student, present or absent, and a note. The core workflow I want is the teacher goes to the classroom overview, it should show the upcoming/active/past sessions (just a summary of maybe the 10 most recent ones) (or the teacher can go to the cclassroom schedule calendar and click on a session). Doing so, the teacher can see the classroom session details, from whcih they can take attendance for all studennts by marking which student was present, which was absent, and add an optional reason.
